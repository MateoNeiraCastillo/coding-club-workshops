# 💻 Coding Club Workshops

👋 **Hey, welcome!**

This is where we keep the code from our Coding Club workshops. If you came to one and want to look at the code again, or you missed one and want to try it on your own, you're in the right place.

**Never programmed before? No problem.** This page explains everything step by step. You don't need to install anything, and you don't need to know how GitHub works.

---

## 🤔 First, what am I looking at?

A few words you'll see around here:

| Word | What it means |
|---|---|
| **GitHub** | A website where programmers save and share code. This page is on GitHub. |
| **Repository (repo)** | A project on GitHub, like a shared folder. This whole page is one repo. |
| **Folder** | Just like the folders on your computer. Each workshop has its own. |
| **Notebook** (`.ipynb`) | A file that mixes text explanations with pieces of code you can run. It's what we use in the workshops. |
| **Google Colab** | A free Google website that opens notebooks and runs the code for you, right in your browser. |
| **Cell** | One block inside a notebook. Some cells have text, others have code. |

## 🗂️ How this repo is organized

```
coding-club-workshops/
├── README.md        ← this page
├── LICENSE          ← says you're free to use and share this code
└── (one folder per workshop, added as we do them)
```

Every workshop will get **its own folder**, numbered in the order we do them (`01-...`, `02-...`). Inside each one you'll find:

- A **README** explaining what we built and what you learn
- The **notebooks** with the code
- Sometimes **example files** and the **slides** from the session

Most workshops will have **two versions** of the notebook:

| Version | What it is | When to use it |
|---|---|---|
| **Workshop** | Has exercises with blank spaces for you to complete | You want to practise |
| **Solutions** | The same notebook, already solved | You're stuck or want to check your answer |

> 💡 Try the exercises first and only look at the solutions if you're stuck. You'll learn way more that way.

## 🚀 How to open and run the code

You only need a **laptop** and a **Google account** (the same one you use for Gmail works).

**1. Open the workshop's folder**
Click its name in the list of files at the top of this page.

**2. Click the "Open in Colab" button**
Each workshop's README has a button like this one:

![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)

It opens the notebook in Google Colab. If it asks, sign in with your Google account.

**3. Save your own copy** ⚠️ *important*
In Colab, go to **File → Save a copy in Drive**. This creates your own version where you can change anything. If you skip this step, your changes won't be saved.

**4. Run the code**
Click on a code cell and press **Shift + Enter** (or the ▶️ button on its left). The result appears just below the cell.

**5. Go in order**
Run the cells from top to bottom, one by one. Cells often need something from the ones before them.

That's it! You're programming 🎉

## 🆘 Something's not working?

Don't worry, errors are completely normal, even for experienced programmers. These fix most problems:

| What you see | What to do |
|---|---|
| A red message that says **`NameError`** | You probably skipped a cell. Go to **Runtime → Run all**, or run the cells again from the top. |
| **"Disconnected"** at the top | Colab disconnects after a while without activity. Click **Reconnect** and run the cells again from the top. |
| Your changes disappeared | You were editing the original. Use **File → Save a copy in Drive** next time. |
| Any other red error | Read the **last line** of the message: it usually says what went wrong. |

**Still stuck?** Message any Coding Club officer, or [open an issue](../../issues) here describing what happened. There are no dumb questions 🙂
