# 💻 Coding Club Workshops

👋 **Hey, welcome!**

This is where we keep the code from our Coding Club workshops. Came to one and want to look at the code again? Missed one and want to try it on your own? You're in the right place.

**Never programmed before? No problem.** You don't need to install anything or know how GitHub works.

---

## 🗂️ How it's organized

Each workshop gets **its own folder**, numbered in the order we do them (`01-...`, `02-...`). Inside you'll find a README explaining what we built, the code, and sometimes the slides.

Most workshops have **two notebooks**:
- **Workshop:** exercises for you to complete
- **Solutions:** the same thing, already solved (try first, peek only if you're stuck 😉)

---

## 🚀 How to open and run the code

All you need is a laptop and a Google account.

1. **Open the workshop's folder** from the list of files above.
2. **Click "Open in Colab"** in its README. The code opens in Google Colab, right in your browser.
3. **Save your own copy** ⚠️ with **File → Save a copy in Drive**, or your changes won't be saved.
4. **Run the code:** click a cell and press **Shift + Enter**.
5. **Go in order,** from top to bottom.

That's it, you're programming 🎉

---

## 🆘 Something's not working?

- **Red error saying `NameError`?** You skipped a cell. Go to **Runtime → Run all**.
- **Says "Disconnected"?** Click **Reconnect** and run the cells again from the top.

Still stuck? Message any Coding Club officer or [open an issue](../../issues). There are no dumb questions 🙂
